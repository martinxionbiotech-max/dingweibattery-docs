# Factory Audit Framework

For OEM and private-label buyers, a factory audit is the most reliable way to verify a battery manufacturer's production quality and claims. This framework outlines the key areas to evaluate.

## Audit Checklist

### 1. Certifications
- IATF 16949 (automotive quality)
- ISO 9001 (quality management)
- ISO 45001 / OHSAS 18001 (occupational health & safety)
- Verify certificates are current and cover the relevant production lines.

### 2. Production Infrastructure
- Factory area and layout
- Number of automated production lines
- Annual and daily production capacity
- Whether capacity matches your volume requirements

### 3. Quality Control Process
- Incoming material inspection
- In-process testing
- Final product testing (CCA, capacity, RC)
- Batch traceability and documentation

### 4. Documentation Package
- Batch-specific test data
- Certificate of Analysis (COA) equivalent for batteries
- Dimensional and terminal verification reports
- Shipping and warranty documentation

## Red Flags to Watch

- Certifications that cannot be independently verified
- No batch traceability or test documentation
- Unwillingness to share production process details
- Capacity claims that do not match physical infrastructure
