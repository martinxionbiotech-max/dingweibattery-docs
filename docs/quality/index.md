# Quality Control Framework

Dingwei Battery's quality control framework is built on the manufacturing certifications of **Chengguang Power Tech Co., Ltd.** — IATF 16949, ISO 9001, ISO 45001, and OHSAS 18001. This framework governs how every battery is specified, tested, and documented.

## Certification Overview

| Certification | Scope |
|---|---|
| IATF 16949 | Automotive quality management system |
| ISO 9001 | General quality management system |
| ISO 45001 | Occupational health and safety |
| OHSAS 18001 | Occupational health and safety assessment |

## Production Infrastructure

- **Factory area**: 200,000 m²
- **Automated production lines**: 18
- **Annual capacity**: 10,000,000 KVAh
- **Daily output**: 40,000 batteries
- **Export markets**: 70+ countries

## Key Quality Processes

- [CCA Testing](cca-testing.md) — cold cranking amps verification
- [Capacity & Reserve](capacity-reserve.md) — amp-hour and reserve capacity measurement
- [Factory Audit](factory-audit.md) — supplier audit framework for OEM buyers

## Documentation

Each production batch is documented with test data confirming the battery's electrical and dimensional specifications. Contact the manufacturer for batch-specific documentation packages.
