# DIN 58827 Battery (DIN88)

The **58827** is a DIN **DIN88** group-size automotive battery designed for European-market vehicles with standard European terminal and hold-down layouts.

## Key Specifications

| Field | Value |
|---|---|
| Standard | DIN (Deutsches Institut für Normung) |
| Group Size | DIN88 |
| Voltage | 12V |
| Terminal Type | DIN terminals (confirm polarity) |
| Application | European passenger and light commercial vehicles |

## Dimensions

Dimensions are confirmed per production batch. Contact the manufacturer for exact case dimensions (length × width × height) matched to your vehicle's battery tray.

## Electrical Performance

- **CCA** — cold cranking amps, measured to the EN/DIN test basis (−18°C). See [CCA Testing](../quality/cca-testing.md).
- **Capacity (Ah)** — amp-hour rating at the C20 rate.
- **Reserve Capacity (RC)** — minutes at a defined discharge.

## Application Notes

The DIN88 group size is common in European vehicles. Confirm terminal layout (right/left positive), hold-down type, and venting requirements before specifying.
