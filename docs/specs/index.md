## Specification Fields Explained

Each specification page includes:

- **Dimensions** — length × width × height (mm), case size
- **Terminal type** — polarity and terminal layout
- **Capacity** — amp-hour (Ah) at the C20 rate
- **CCA** — cold cranking amps, test-basis dependent (JIS/EN/SAE/DIN)
- **Reserve Capacity (RC)** — minutes at a defined discharge
- **Application** — vehicle type and usage

## Important: CCA Test Basis

CCA is **not** a single universal number. The same battery can show a different CCA under JIS (−15°C) than under EN/SAE/DIN (−18°C). Always confirm the test standard when comparing CCA values. See [CCA Testing](../quality/cca-testing.md) for the full methodology.
