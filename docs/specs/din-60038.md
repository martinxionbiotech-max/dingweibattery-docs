# DIN 60038 Battery (DIN100)

The **60038** is a DIN **DIN100** group-size automotive battery designed for high-capacity starting applications in premium European vehicles and light commercial fleets.

## Key Specifications

| Field | Value |
|---|---|
| Standard | DIN (Deutsches Institut für Normung) |
| Group Size | DIN100 |
| Voltage | 12V |
| Terminal Type | DIN terminals (confirm polarity) |
| Application | Premium European vehicles, light commercial, start-stop |

## Dimensions

Dimensions are confirmed per production batch. Contact the manufacturer for exact case dimensions (length × width × height) matched to your vehicle's battery tray.

## Electrical Performance

- **CCA** — cold cranking amps, measured to the EN/DIN test basis (−18°C). See [CCA Testing](../quality/cca-testing.md).
- **Capacity (Ah)** — amp-hour rating at the C20 rate.
- **Reserve Capacity (RC)** — extended reserve for start-stop and high-accessory vehicles.

## Application Notes

The DIN100 group size serves high-capacity European applications, including start-stop systems that demand enhanced cycling performance. Confirm AGM vs flooded requirements and battery management system (BMS) compatibility before specifying.
