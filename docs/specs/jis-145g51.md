# JIS 145G51 (N150) Battery

The **145G51** is a JIS **N150** group-size automotive battery designed for heavy-duty starting applications in trucks and commercial vehicles operating in Japanese and Asian markets.

## Key Specifications

| Field | Value |
|---|---|
| Standard | JIS (Japanese Industrial Standard) |
| Group Size | N150 |
| Voltage | 12V |
| Terminal Type | JIS posts (confirm polarity) |
| Application | Heavy-duty trucks, buses, commercial vehicles |

## Dimensions

Dimensions are confirmed per production batch. Contact the manufacturer for exact case dimensions (length × width × height) matched to your vehicle's battery tray.

## Electrical Performance

- **CCA** — cold cranking amps, measured to the JIS test basis (−15°C). See [CCA Testing](../quality/cca-testing.md).
- **Capacity (Ah)** — amp-hour rating at the C20 rate. Confirm the exact value for your batch.

## Application Notes

The N150 group size is common in Japanese and Asian-market heavy vehicles. Always confirm terminal layout (right/left positive) and hold-down requirements before specifying.
