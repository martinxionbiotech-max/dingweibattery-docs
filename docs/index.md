# Dingwei Battery Technical Documentation

Welcome to the official technical documentation center for **Dingwei Battery**, an OEM and private-label automotive battery program manufactured by **Chengguang Power Tech Co., Ltd.**

This knowledge base provides the technical specifications, quality control framework, testing standards, and sourcing guidance that researchers, distributors, and OEM buyers need to evaluate and specify automotive batteries correctly.

## Our Mission

Dingwei Battery exists to make OEM and private-label battery sourcing transparent and technically rigorous. We publish the specifications, test methods, and quality framework behind our battery models so buyers can specify, compare, and source batteries with confidence.

## Who Should Use This Documentation

| Audience | What You'll Find Here |
|---|---|
| OEM Buyers | Battery specifications, MOQ, lead time, RFQ guidance |
| Distributors | Standards comparison, shipping, warranty terms |
| Private-Label Brands | Private-label program mechanics, development process |
| Engineers | CCA testing, capacity/reserve capacity, dimensional specs |
| Quality Teams | Quality control framework, factory audit framework |
| Procurement | Supplier checklist, documentation packages |

## Documentation Scope

This documentation covers:

- **Battery specifications** — JIS and DIN standard models with dimensional, electrical, and test data
- **Testing & quality** — CCA test methodology, capacity measurement, factory audit framework
- **OEM & private label** — program mechanics, MOQ/lead time, RFQ preparation
- **Standards & regulatory** — JIS/DIN/BCI/SAE/EN comparison, shipping and warranty

## Standards Reference

| Standard | Scope | Common Markets |
|---|---|---|
| JIS | Japanese Industrial Standard (N-series) | Japan, Asia |
| DIN | Deutsches Institut für Normung | Germany, Europe |
| BCI | Battery Council International (group sizes) | North America |
| SAE | Society of Automotive Engineers | North America |
| EN | European Norm | Europe |
